# Sentry Six

A dark Liquid Glass interface for Sentry Six Manager. Choose **Sentry Six** in
Original's Settings > Interface. In this pack, interface selection is under
Settings > Look & interface. Original remains the default.

Overview, Footage, Activity, Recycle Bin, Health and Settings use the new layout.
Viewer, Encoder and Sentry USB retain their shared code with the family theme.
On a phone, use More for the remaining pages. Footage > Trips & map opens the
shared trip, driving and map views. Health > Server details keeps the detailed
statistics and CSV export reachable.

Open `/original` to use the built-in interface in the current browser. The pack
contains no external assets or network dependencies.
